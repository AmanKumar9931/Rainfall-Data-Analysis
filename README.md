# 🌧️ Rainfall Analysis Dashboard | Power BI

## 📌 Project Overview

The **Rainfall Analysis Dashboard** is an interactive Power BI project designed to analyze and visualize rainfall patterns across different locations and time periods. The dashboard transforms raw rainfall data into meaningful visual insights, helping users understand **rainfall trends, seasonal variations, regional differences, and overall precipitation patterns**.

## 🎯 Problem Statement

Rainfall data can be difficult to analyze when it is stored in large and unstructured datasets. The objective of this project is to develop an interactive dashboard that provides a clear and user-friendly view of rainfall patterns and allows users to easily compare rainfall across different **years, months, and locations**.

## 📊 Dashboard Features

* 📅 Analyze rainfall trends over different time periods
* 📍 Compare rainfall across different locations/regions
* 📈 Visualize monthly and yearly rainfall patterns
* 🔎 Interactive filters and slicers for dynamic analysis
* 📊 KPI cards for key rainfall metrics
* 🌧️ Identify periods with high and low rainfall
* 📉 Analyze seasonal rainfall variations
* 🖱️ Interactive charts that update based on selected filters
* 🏷️ Dynamic dashboard titles based on user selections

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Creating calculated measures and KPIs
* **Data Visualization** – Charts, cards, slicers, and interactive visuals

## 🔄 Project Workflow

**Raw Data → Data Cleaning → Data Transformation → Data Modeling → DAX Measures → Visualization → Interactive Dashboard**

### 1. Data Preparation

The rainfall dataset was imported into Power BI and cleaned using **Power Query**. Missing values, incorrect data types, and unnecessary columns were handled before analysis.

### 2. Data Transformation

The data was transformed into an analysis-ready format by modifying columns, creating required fields, and preparing date-related information.

### 3. Data Analysis

DAX measures were created to calculate important rainfall metrics and support dynamic analysis.

### 4. Dashboard Development

Interactive visuals, KPI cards, slicers, and charts were used to create an easy-to-understand dashboard.

## 🧮 DAX

DAX was used to create measures for rainfall analysis, such as:

* Total Rainfall
* Average Rainfall
* Maximum Rainfall
* Minimum Rainfall
* Monthly/Yearly Rainfall
* Rainfall comparisons based on selected filters
